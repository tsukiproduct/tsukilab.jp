# チャンネル設定(YouTube Studio に貼り付ける内容)

## 基本情報(YouTube Studio → カスタマイズ → 基本情報)

**名前**
この世界のバグ図鑑

**ハンドル**(上から優先。2026-10-01 時点で空きを確認済み。登録時に再確認してください)
1. @この世界のバグ図鑑
2. @konosekai_bug
3. @bug_zukan
※ @bugzukan は使用中

**説明**(約480文字。上限1000文字)
```
ニュースで見つかった「この世界の仕様の不具合」を、毎日ひとつ報告するチャンネルです。

報告係の春日部つむぎと、すぐ驚くずんだもんが、
最新の研究や世界のニュースに隠れた「バグ」を、地図・3D・図解で分かりやすく解説します。

▼毎回の流れ
・バグの発見 → 原因の調査 → 正体・修正 → バグ報告書に判子
・ステータスは「未解決」「仕様です」「修正済み」「修正パッチ配布中」「誤報でした」など

▼大切にしていること
・数字と固有名詞はすべて出典を確認し、概要欄に載せています
・仮説は仮説として紹介します
・間違いが見つかったら、概要欄と固定コメントで訂正します

あなたが見つけた「この世界のバグ」も、コメントで報告してください。
次の報告書で取り上げるかもしれません。

毎日更新。

音声：VOICEVOX:ずんだもん / VOICEVOX:春日部つむぎ
立ち絵：坂本アヒル様
```

**リンク**(任意)
- 公式サイトなどがあれば追加。無ければ空欄で問題ありません。

## アップロード動画のデフォルト設定(設定 → アップロード動画のデフォルト設定)
- **説明**:
```

立ち絵：坂本アヒル様
```
  ※毎回の概要欄は description.txt で上書きします。これは貼り忘れたときの保険です。
- **公開設定**: 非公開(予約投稿で公開する運用のため)
- **カテゴリ**: 教育
- **動画の言語 / タイトルと説明の言語**: 日本語
- **タグ**(カンマ区切り):
```
この世界のバグ図鑑,ずんだもん,春日部つむぎ,雑学,解説,ニュース解説,科学,世界の不思議,VOICEVOX
```
- **詳細設定 → 改変または合成されたコンテンツ**: 原則「いいえ」。
  実写風の生成画像で実際の出来事を描いた回だけ「はい」にする(運営仕様書 6章)。
- **コメント**: 公開(不適切な可能性があるコメントは保留)

## 再生リスト(作っておくと続けて見られやすくなる)
| 再生リスト名 | 説明 |
|---|---|
| バグ報告書(全話) | 全エピソードを公開順に |
| 修正パッチ配布中のバグ | 国連決議・制度変更など「直りつつあるバグ」 |
| 仕様でした | 原因が分かって「実はそういうもの」だった回 |
| 未解決のバグ | まだ正体が分かっていない回 |
| 寝ながら聴けるバグ図鑑 | 月1回の総集編 |

## 既存チャンネルを転用する場合の注意
- 以前の動画が今回の内容と違うジャンルなら、**削除ではなく「非公開」**にしておくのが安全です。
  ジャンルの違う動画が混ざると、おすすめに載せる相手をYouTubeが判断しにくくなります。
- 名前の変更は14日間に2回まで、ハンドルの変更も14日間に2回までという制限があります(変更前に確認を)。
- 収益化の審査に関係する「総再生時間」は、過去12か月の公開動画が対象です。

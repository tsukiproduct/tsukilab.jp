# 参照画像(assets/refs/)

台本の `image` に書いたファイル名の画像をここに置くと、ポラロイド風の枠で動画に出ます。
画像が無い間は「ここに参照画像」と出ます。

台本での指定例:
    {"image": "racetrack_stones.jpg", "credit": "撮影者名 / 配布元", "license": "CC BY-SA 4.0"}

動画下部のカードに `出典: {credit} / {license}` が自動で入ります。

## サンプル台本で必要な画像
| ファイル名 | 内容 | 候補 |
|---|---|---|
| racetrack_stones.jpg | 乾いた湖底に石と引きずった跡が並ぶ風景 | 写真(権利が明確なもの) |
| gps_stone_research.jpg | GPSをつけた石・観測の様子 | 写真、またはイメージ図 |
| ice_sheet_playa.jpg | 薄い氷の板が石を押す仕組み | イメージ図(図解) |

## 使う前に
- 写真は、パブリックドメインやCCなど利用条件が明確なものを優先し、出典とライセンスを必ず表記する。
- 生成AIの画像を使う場合は「イメージ図」と明記し、実在の出来事の写真に見えるものは避ける。
  YouTubeには、現実と紛らわしい合成コンテンツの開示ルールがあるため、公式ヘルプで確認すること。
- 「引用」として使う場合は、日本の著作権法32条の要件(公正な慣行、正当な範囲、
  引用部分の明瞭な区分、本編が主で引用が従、出典の明示)を満たす必要がある。迷う画像は使わない。

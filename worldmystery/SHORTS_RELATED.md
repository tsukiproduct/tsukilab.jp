# ショートの「関連動画」設定リスト

## 自分で設定する手順(1本 約30秒)
1. パソコンで YouTube Studio → 左の「コンテンツ」→ 上のタブ「ショート」。
2. 設定するショートの鉛筆マーク(詳細)を開く。
3. 「関連動画」の欄で、下の表の**本編**を選ぶ(タイトルの最初の数文字で検索できる)。
4. 右上の「保存」。
- 本編が**公開された後**でないと、候補に出ません。予約中の本編は、公開日を過ぎてから設定してください。
- スマホのアプリの場合: ショートの編集 → 「関連動画」でも設定できます。

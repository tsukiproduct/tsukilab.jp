## 2. シリーズの「型」(量産型と判定されないための核)
毎回同じ「仕掛け」で締めると、シリーズとして覚えてもらえて、収益化の審査でも独自性を示せます。
下の例はバグ図鑑のもの。報告書と判子以外の仕掛け(ランキング、判定、採点、地図に旗を立てる など)でもかまいません。「おまかせ」なら Claude が提案します。
- 毎回の見立て: {{例: バグ報告書 / 事件ファイル / 調査レポート / 診断カルテ(※医療風は避ける)}}
- 札の言葉(サムネ・オープニング): {{例: 「バグ報告 #001」→「事件ファイル #001」}}
- 締めの判子(ステータス)の語彙(5〜6個で固定): {{例: 未解決 / 調査中 / 仕様です / 修正済み / 誤報でした}}
- 報告書の項目名(5つ。最後は判子の欄): {{例: 対象 / 発生場所 / 原因の報告 / 深刻度 / ステータス}}

# 仕上げの確認項目と、実際に起きた失敗

## A. 渡す前に必ず見る(動画)
- [ ] 冒頭20秒で「謎」が見える。オープニングは0秒に置いていない
- [ ] 字幕が単語の途中で不自然に切れていない。1行に収まっている。話者の色が合っている
- [ ] 図・年表・グラフの文字が、縮小表示でも読める大きさ(表示枠 `box` を小さくしすぎない)
- [ ] 動く図の速さが目で追える(1段階あたり3〜4秒が目安)
- [ ] 図のハイライトや色が、別の図に紛れ込んでいない(部品を使い回すときは設定を初期化)
- [ ] 章バーとチャプターが合っている。チャプターは 0:00 から始まり、3つ以上、各10秒以上
- [ ] 報告書カードと判子(ステータス)が正しい
- [ ] 声が BGM より十分大きい(発話中に約20dB差)。仕上がりは -16 LUFS 前後
- [ ] 画像の出典が画面と概要欄に入っている。台本の数字はすべて出典で確認済み

## B. サムネイル・タイトル・概要欄
- [ ] 縮小表示(`preview_small.png`)で文字が読める。8文字前後・2行まで
- [ ] 図の大事な文字が切れていない(`crop` / `photo_size` / `photo_pos` で調整)
- [ ] 右下(再生時間の表示)に大事なものを置いていない
- [ ] タイトルとサムネが同じ言葉を繰り返していない。中身と合わない煽りはしない
- [ ] 概要欄: 冒頭2行の要約、チャプター、報告書、コメント募集、クレジット(声・立ち絵・BGM・画像・出典)、ハッシュタグ3つ

## C. ショート
- [ ] 見出しが3行でも本編の映像に重なっていない
- [ ] 20〜40秒。途中で文が切れていない
- [ ] ショート用サムネ(9:16)の図が中身と合っている(合う図がなければ図なしにする)

## D. ファイルの渡し方
- [ ] 1ファイル30MB以内(超えたら再圧縮)
- [ ] zip の中のファイル名は英数字(日本語名は Windows で文字化けする)
- [ ] PowerShell スクリプトは UTF-8(BOM付き)・CRLF
- [ ] 送ったファイルはチャットの「添付」になるだけなので、ダウンロードが必要だと伝える

## E. 実際に起きた失敗(繰り返さない)
| 起きたこと | 対策 |
|---|---|
| API(監査前のアプリ)でアップロードすると、動画が非公開に固定され、持ち主でも公開にできない | Studio から手動で上げる。自動化するなら監査を通すか、Zapier などの監査済みサービスを使う |
| 予約中の動画で「テストと比較」が使えない | 予約中は非公開の扱い。予約時はA案だけ設定し、公開後にB・Cを追加する。ショート・プレミア公開・子ども向けも対象外 |
| 「ショートにサムネは付けられない」と誤って伝えた | 今はPCの Studio で9:16のサムネを設定できる(確認済みアカウント)。仕様は変わるので、毎回公式ヘルプで確かめる |
| 曜日を思い込みで書いた | 予約表の曜日はカレンダーで計算して確かめる |
| ネットの話題の「定説」が誤りだった(例: ギネスの起源) | 一次情報で確かめ、誤りなら「実は」として扱う |
| 図の表示枠が小さく、文字が読めなかった | 既定の枠を使うか、確認用の静止画で必ず読めるか見る |
| ショートの3行の見出しが映像に重なった | 見出しの位置は最後の行を基準にそろえる(修正済み) |
| 連番画像(数千枚)や大きな動画をコミットしてしまった | `.gitignore` に `assets/refs/*/`・`out/` などを入れ、コミット前に `git status` を見る |
| 確認用に `--dry` を実行して、完成済みの動画を上書きした | 確認は `--still 秒 出力.png` を使う。`--dry` は `--out` で別の場所に出す |
| PCにフォルダを作ってほしいと言われたが、クラウドのセッションからはPCに触れない | 整理用スクリプトを渡すか、PC上で Claude(Desktop アプリのローカル実行など)を使ってもらう |
| 健康の話題を扱いかけた | AIキャラによる健康・医療・金融・法律の助言は、収益化の対象外と明言されている。題材の段階で除く |

# プロンプト②: 1本を作る(毎日用)

立ち上げが済んだリポジトリで、`---` から下を貼ってください。
題材を指定したいときは `{{題材}}` に書き、おまかせなら「おまかせ」のままにします。

---

`{{フォルダ名}}/CLAUDE.md`、`CHANNEL_SPEC.md`、`topics.json` を読み、その方針どおりに次の1本を作ってください。
題材: {{題材 / おまかせ}}

## 手順
1. **題材選び**(おまかせのとき): 直近 {{7}} 日のニュースから、「最近のニュース × 昔からの定番の疑問」が重なるものを5つ挙げ、
   それぞれ需要(同テーマ上位10本の再生数の中央値)と出典を示して、数字が取れそうな順に並べる。
   `python3 tools/topics.py check キーワード` で過去回と重ならないか確かめる。扱わない話題(仕様書)は除く。
2. **事実確認**: 元記事と一次情報(論文・公式発表)を読む。台本に使う数字・固有名詞・日付はすべて出典で確認し、
   台本の `sources` に書く。仮説は「〜という説」と明示する。
3. **台本**: 仕様書の構成(フック → オープニング → 挨拶 → 4章 → 報告書と判子 → 締め)で書く。
   - 冒頭20秒で「謎」を見せ、答えは最後と予告する。挨拶より先に本題。
   - 毎回1つ以上「動く図」を入れる(`tools/figs.py` の部品を使うか、新しく作る)。静止画を並べるだけにしない。
   - 1行は短く(字幕は1行44文字以内に収まる長さ)。強調は `[[語]]`。キャラの話し方と役割を守る。
   - 毎回変えるもの: 題材・結論・章の名前・見せ場の種類・笑いの入れ方・ステータス。
   - `publish` にタイトル3案(「なぜ/理由」型を1つ入れる)、サムネ3案(8文字前後・2行まで、タイトルと別の言葉)、
     `shorts` に切り抜き区間2つ(各20〜40秒、見出しは3行まで)。
4. **制作**: `bash tools/produce.sh scripts/epNNN_xxx.json`
5. **自分で確認**: `check.png`(本編4場面)、`preview_small.png`(サムネ3案を実寸と縮小で)、図の場面の静止画、
   ショートの1コマとショート用サムネを見て、`kit/05_CHECKLIST.md` を全項目確認する。
   直したら作り直して、もう一度確認する。
6. **記録**: `topics.json` に id・status・keywords・demand・sources を書き、コミットしてプッシュする。
7. **渡す**: 本編(30MB以内)・ショート2本・サムネとテキストのzip(中は英数字の名前)を送り、
   公開日時とショートの公開日時、Studio での設定手順を一覧で伝える。

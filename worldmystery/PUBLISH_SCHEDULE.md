# 投稿スケジュール(YouTube Studio の予約投稿で設定)

## 時刻の決め方(調査結果)
- 日本の YouTube 視聴のピークは **21〜22時**(平日・週末とも)。スマホ利用のピークも22時ごろ。
- 公開から処理・通知が行き渡るまでの時間を見込み、**ピークの1〜2時間前(19:00)に本編**を公開する。
- ショートは本編の翌日に出し、関連動画として本編をリンクする(本編が先に公開されていないとリンクできないため)。
  昼休み(12:00)と夜のピーク前(21:30)に1本ずつ。
- YouTube は「公開時刻そのものは長期の伸びにほとんど影響せず、継続と視聴者の反応が重要」としている。
  2〜3週間たったら、YouTube Studio の「視聴者がYouTubeにアクセスしている時間帯」を見て時刻を調整する。

## 毎回の手順(1本あたり約5分)
1. Studio で `video.mp4` をアップロード → タイトル(titles.txt の案A)・概要欄(description.txt)・サムネ(thumbnail_A.jpg)を設定
2. 公開設定を「スケジュール」にして上の日時を指定
3. ショート2本(short_1.mp4 / short_2.mp4)も同様にアップロードし、タイトルは shorts.txt から。
   編集画面の「関連動画」に本編を設定し、翌日の日時で予約
4. 本編の公開後(19:00以降)に、Studio のサムネイル欄の「テストと比較」で案B・案Cを追加。
   予約中は「非公開」の扱いなので追加できない。プレミア公開・子ども向けにすると使えない。テスト中にタイトルやサムネを変えるとテストが止まる

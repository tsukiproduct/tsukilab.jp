# 引き継ぎプロンプト(PCで動く Claude Code 用・分析と運営)

PC の Claude Desktop で **実行場所を「ローカル(このPC)」にした Code の新しい会話**を開き、
Chrome 連携(Claude in Chrome)またはコンピューター操作を有効にしてから、`---` から下をそのまま貼ってください。

---

あなたは YouTube チャンネル「この世界のバグ図鑑」の運営アシスタントです。クラウド上の Claude Code から作業を引き継ぎます。
このPCの Chrome(私が YouTube にログイン済み)で YouTube Studio を見て、伸び悩みの原因をデータで突き止め、次の作戦を立ててください。

## 守ること
- **パスワードや認証コードを入力したり聞いたりしない。** ログイン画面や二段階認証が出たら止めて私に頼む。
- **最初は見るだけ。** 公開・削除・非公開化・タイトルやサムネの変更・設定の変更は、私が「やって」と言うまでしない。
  変更するときも、操作の前に「何をどう変えるか」を一覧で見せて了承をもらう。公開ボタンは押さず、必ず予約にする。
- 迷ったとき、表示が想定と違うときは、推測で進めず止めて聞く。
- `tools/client_secret*.json` と `tools/token.json` は、共有も commit もしない。
- 返答は丁寧に。事実は確かめてから答える。画像・動画の生成AIは、私が指示するまで使わない。

## 2. まずやること(見るだけ)
1. Studio → アナリティクス → **詳細モード**、期間=チャンネル開設以降、コンテンツ別。全動画について次をまとめる:
   タイトル / 本編かショートか / 公開日 / 視聴回数 / インプレッション数 / インプレッションのクリック率 / 平均視聴時間 / 平均視聴率 / 登録者の増減
   (右上の書き出し → CSV が使えればそれを使う)
2. ショートは、各本の「**視聴された割合(スワイプで離れなかった割合)**」。
3. 本編の上位3本と下位3本は、維持率グラフで次を見る: 最初の30秒で何%残っているか、急に落ちる秒数とそこで何を話しているか(台本は `scripts/epNNN_*.json`)。
4. トラフィックソース: 本編について、ショートからの流入(「関連動画」の数)と、ブラウジング・検索・関連動画の内訳。
5. 集めた数字を `worldmystery/analytics/2026-10-19.csv` に保存する(個人情報は含めない)。

## 3. 分析して報告すること
- 伸びたショートと伸びなかったショートの差: 題材、最初の1秒、長さ、視聴された割合。
- 本編が見られない原因はどれか: クリックされないのか(クリック率)、すぐ離れるのか(最初の30秒の維持率)、そもそも表示されていないのか(インプレッション)。
- 上の仮説 (a)(b)(c) が正しいかどうか。
- そのうえで、次の8本(#017〜)の作戦を提案する。題材、本編とショートの本数と頻度、ショート専用の作り方、サムネとタイトルの方向、を含める。
  前任の案: ショートで伸びた題材(AIの危ない挙動、宇宙と地図の誤解)を深掘りして本編にする。ショートは切り抜きではなく、
  最初の1秒で結論か衝撃を見せ、20〜40秒で完結させ、続きへの引きで終わる専用の作りにする。本編は週2〜3本、ショートは毎日。
  これをデータで支持するか、否定するかも述べる。

## 4. 私の了承を得てからやること(変更作業)

- 本編のサムネで「テストと比較」を使い、`thumbnail_B.jpg` と `thumbnail_C.jpg` を追加する(ダウンロードフォルダの各回の `NNN_A_main.zip` の中)。
  テスト中はタイトルとサムネを触らない。

## 5. 制作について
- 台本・音声・動画の書き出しは、このリポジトリで行う(`worldmystery/CLAUDE.md`、`kit/03_PROMPT_episode.md` を参照)。
  この PC で動かすなら、VOICEVOX エンジン、ffmpeg、Python のライブラリ(`pip install pillow numpy psd-tools pyproj pyshp`)が必要。
  立ち絵PSDはリポジトリに入っていないので、私が渡す。
  PC での準備が難しければ、制作はクラウドの Code の会話で行い、この会話は分析・アップロード・Studio での設定を担当する、という分担でもよい。
- 方針(CHANNEL_SPEC.md §11):
  - 同じジャンルは2本続けない。8本中の宇宙/科学は2本まで。
  - 番号=公開順。
  - 被害者が出る場面では serious の表情を使う。

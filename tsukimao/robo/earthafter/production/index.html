制作台

ありがとうは最後まで を動画にするための作業台です。素材がそろうと、カット表とプレビズに自動で絵が入ります。

進め方

  1. ChatGPT で素材を作るClaude がお渡しした「GPT依頼一式（ZIP）」の順番どおりに作ります。俯瞰図 → 背景 → 人物と機械 → 小道具 → 漫画 → カットの基準画。依頼一式は公開のページには載せていません。
  2. できた絵を Claude に送るファイル名は依頼文に書いた名前のまま（例：BG-R1.png）。まとめて送っていただければ、名前を確かめてこのページに置きます。基準画（2×2）は Claude が4カットに切り分けます。
  3. このページで確かめる素材の進み具合、カットごとの絵、プレビズ（仮の通し）で、つながりと尺を観ます。崩れた絵は、依頼一式の「直し用のひな形」で直します。
  4. Lumina で動画にする月真猫さんのお指図があってから始めます。カットごとに「動画の指示文」と「添付する参考」を使います。基準画は最初のコマにせず、参考素材として渡します。
  5. 記録を残す生成のたびに、制作記録 の項目を残します（規約第九条）。

俯瞰図

場所ごとの物の位置とカメラの向きをそろえるための図です。いまは Claude が描いた配置図です。ChatGPT で清書した図が届いたら、それに差し替わります。

素材表

「届いた」は、このページに絵が置かれているものです。台詞の声は、Seedance か ElevenLabs で作った生成音声を参考に使います。

    カット表

    台詞のひらがなとローマ字は、機械で付けた読みを Claude が直したものです。読み違いが残っている場合がありますので、生成の前に目で確かめてください。ローマ字は発音どおり（「は」は wa）にしてあります。

    プレビズ

    カット表の順と秒数で、仮の通しを流します。絵が届いていないカットは、画の説明を文字で出します。旧作の映像を差し込むカットは、旧作の絵コンテを出します。

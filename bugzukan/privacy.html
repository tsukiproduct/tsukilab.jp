プライバシーポリシー

対象：YouTube チャンネル「この世界のバグ図鑑」の運営者が使用する内部ツール「バグ図鑑アップローダー」(以下「本ツール」)

1. 取得する情報

本ツールは、Google の OAuth 認証を通じて、運営者自身の YouTube アカウントに対し、動画のアップロードと、動画のタイトル・説明・サムネイル等の設定を行う権限のみを利用します。運営者以外の利用者の情報は取得しません。

2. 利用目的

運営者が制作した動画を、運営者自身の YouTube チャンネルに投稿・設定するためにのみ利用します。

3. 第三者への提供

取得した認証情報やデータを、第三者に販売・提供することはありません。

4. 保管

認証に必要な情報は、運営者が管理する非公開の環境にのみ保管し、公開のリポジトリやウェブサイトには保存しません。

5. Google API サービスの利用について

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含む)に従います。YouTube API サービスの利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

6. 権限の取り消し

本ツールに付与した権限は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

YouTube チャンネル「この世界のバグ図鑑」の概要ページをご覧ください。

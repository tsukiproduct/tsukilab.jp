# 闇麻雀 〜イカサマなんて生ぬるい〜

四人打ちの一人用ゲーム。月真猫（つきまお）、残（nokosu）、流空（ルシエル）、経経経経減（へへへへへ）から自分の雀士を選び、残る三人と対局します。

## 起動

- **Windows・macOS・Linux**　ZIPを解凍し、`index.html` をChrome、Edge、Firefox、Safariなどの現行ブラウザで開きます。インストールとネット接続は不要です。
- **iPhone・Android**　PCに展開したフォルダで `python -m http.server 8765` を実行します。スマホとPCを同じWi-Fiにつなぎ、スマホのSafariまたはChromeで `http://PCのローカルIP:8765/` を開きます。macOSで `python` が見つからない場合は `python3` を使います。ZIP内のHTMLをファイルアプリでプレビューする方法ではスクリプトが動かない機種があります。

牌をタップまたはクリックすると打牌できます。PCでは左右キーで牌を選び、Enterで打牌できます。立直はボタンを押してから候補の牌を選択。音を出すには「音響 OFF」を押してください。タイトルで通常卓と闇卓、東風戦と半荘戦を選べます。対局は開いているページ内で進行します。

## 試作版監査と実装

| 項目 | 試作版 | この版 |
| --- | --- | --- |
| 進行 | 136枚、配牌、打牌、簡易CPU、東一局のやり直し | 東風戦・半荘戦、親交代と連荘、本場、供託、流局精算と最終順位 |
| 和了 | 基本形と七対子の形判定、固定点 | 役と符、親子別精算、門前・鳴きの差、役満複合、ドラのみの和了排除 |
| 立直・鳴き | 形式的な宣言、鳴きなし | 任意の合法打牌で立直、ツモ切り拘束、チー・ポン・3種類のカン、槍槓、嶺上、フリテン |
| 暴牌 | ロンとツモで別処理。阻止牌を種類単位で記録し、後のロンにも影響 | 同一の和了処理。136枚を個別に追跡し、成立直前の卓を復元。失効範囲は対象となった宣言のみ |
| イカサマ | 山全体を検索して有利な牌を選ぶ | 更新される視線を読み、選んだ牌と生牌の山の次の一枚を交換 |
| 表現 | 既存立ち絵、簡易エフェクト | 選択画面、CSSの牌と立体卓、カメラの寄り、表情差分の暴牌演出、環境音・効果音、縦画面対応 |

実装は牌姿・点数判定、対局状態とCPU、画面と音響に分けています。キャラクターの全身・表情は同梱元の設定画から切り出し、顔・髪型・体格は描き直していません。カットインの動きは原画のレイヤーとカメラのモーションで付け、牌・卓の立体感はCSSで作っています。元の設定画・キービジュアルは `reference` に収録しています。

## 闇卓

集中は打牌で5、立直成立で13、自分の手番で一度だけ「集中」を押すと12増えます。すり替えは通常のツモ手番に一度だけでき、集中18を使います。全員がよそ見している間に牌を選ぶと、その牌が山の次の牌と交換されます。監視中は集中を消費し、交換は失敗します。

| 雀士 | 暴牌 | 消費 | 特性 |
| --- | --- | ---: | --- |
| 月真猫 | 月蝕 | 72 | 阻止後の次回打牌で集中＋12 |
| 残 | 残響 | 62 | 4人の中で最も低い集中消費 |
| 流空 | 虚空 | 78 | 自分で使うと、次の通常ツモ手番の監視が外れる |
| 経経経経減 | 経典崩壊 | 84 | 和了を宣言した相手の集中を30削る |

相手が和了を宣言すると、集中が足りる場合に暴牌を選べます。CPUも集中が足りていて、3,900点以上の和了で自分に支払いが発生する場合に阻止します。ツモを阻止すると、同じツモ牌を持ったまま打牌に戻ります。ロンを阻止すると、同じ捨て牌に対する次順位のロン、鳴き、次手番の順に処理します。槍槓を阻止した場合も同じ槓への応答に戻ります。点数・供託・山・王牌はその和了では精算されません。

## 通常卓の採用ルール

- 25,000点で始まり、プレイヤーが起家。東風戦は東四局まで、半荘戦は南四局まで。親の和了と流局テンパイで連荘し、オーラスも連荘条件を適用。持ち点がマイナスでも続行し、最終局後の残り供託は首位に加算。同点時は起家に近い席を上位とします。
- 喰いタン、後付け、一発、裏ドラ、赤五各1枚、槓ドラ即表示、形式テンパイあり。一翻縛り。立直には1,000点と生牌の山に4枚以上が必要です。
- ロンは頭ハネ。チーよりポン・大明槓を優先。喰い替え禁止。立直後の暗槓は待ちと面子構成を保つ、引いた四枚目に限ります。
- 同巡フリテンは役の有無を問わず、次の自分のツモで解除。立直後の見逃しはその局の間フリテン。暗槓の槍槓は国士無双のみ認めます。
- 流局は山切れのみ。九種九牌、四風連打、四家立直、四槓散了、流し満貫、人和、同時和了、ダブロン、延長戦は採用していません。
- 連風牌の雀頭は4符。30符4翻・60符3翻は切り上げ満貫。数え役満あり。国士十三面待ち・四暗刻単騎・純正九蓮・大四喜の単体ダブル役満は採用せず、異なる役満の複合は加算。大三元と大四喜の包を採用します。

[日本プロ麻雀協会公式ルール](https://npm2001.com/about/rule/) ／ [日本麻雀連盟リーチ麻雀規定](https://www.nihon-majan.org/ritimajyanruru.html) ／ [最高位戦日本プロ麻雀協会競技規定](https://saikouisen.com/pdf/saikouisen_regulation.pdf)

## 再検証

Node.js 22以上で、展開したフォルダから `node --test` を実行します。追加ライブラリは不要です。点数計算、鳴き、フリテン、立直後の暗槓、ロン・ツモの阻止と復帰、すり替え、UIのイベント処理を検証します。固定乱数で全12対局を最終順位まで進め、各手番で136枚と供託込み100,000点の保存を確認します。対局画面の実ブラウザ描画、音の出力、スマホ実機でのタッチ操作は未確認です。

# スロットぱちんかす

A+AT仕様のパチスロシミュレーター。内部抽選は実機同様の16bit乱数・分母65536・減算方式。

## 遊ぶ

| | URL |
|---|---|
| 通常モード | [/game/slot/pachinkasu/](./) |
| デバッグモード | [/game/slot/pachinkasu/debug.html](./debug.html)（= `index.html?debug=1`） |

デバッグモードでは左側にパネルが出て、成立フラグの強制・フリーズ/AT当選の強制・
AT即開始・演出速度の変更（最大20倍）・自動プレイ・内部状態のライブ表示ができる。
`?debug=1` が無いと `src/ui/debug.js` は読み込まれない。

操作: マウス／タップのほか、キーボードも可（SPACE=BET→レバー、←↓→ or 1/2/3=停止、M=メニュー）。
スマホは下パネルを1点タップするだけで MAX BET→レバー→左→中→右 と順送りされる。

**音が出ます。** 効果音は WebAudio の合成音（`src/ui/sound.js`）で、役ごとに入賞音が違う。
BIGボーナス中は液晶で MV が音アリで流れる（`assets/movies/mv_big_loop.mp4`・約15MB）。

## ローカル開発

```bash
npm run dev        # http://localhost:3000（ESモジュールのため file:// では動かない）
npm run sim        # 出玉検証（200万G以上推奨）
npm run test:reel  # リール制御の総当たり検証
```

- 仕様書: `docs/SPEC.md`（数値の正はここ）
- スタイルガイド: `docs/STYLE.md`（素材を作る前に必ず読む）
- 開発方針: `CLAUDE.md`

## このリポジトリに含まれないもの

**`assets/_source/`（元シート画像・約43MB）は含まれていない。**
サイト用リポジトリを軽く保つため除外している。実行には不要だが、
`python tools/crop.py`（素材の再生成）と `npm run movies` を動かすには必要。
素材を作り直す場合はローカルの作業ディレクトリで実行し、生成物だけをここへ反映すること。

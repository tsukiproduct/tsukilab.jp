# スタイルガイド — レトロ4号機路線

仕様書 §14.8 が要求する「制作開始前に確定すべきスタイルガイド」。
**全素材はこの1枚に従う。** 素材を追加・差し替えるときは必ずここを先に読むこと。

方向性: **1990年代・4号機時代のパチスロ筐体**。
蛍光アクリルにシルクスクリーン印刷した下パネル、ベタ塗りの図柄、ドット表示の液晶。

---

## 1. なぜこの路線か

4号機時代のパネルは「良い意味で素朴、悪い意味でやぼったい」と評される。
この**やぼったさ＝情報量の少なさ**こそが、いま逆に強い。理由は3つ。

1. **図柄の視認性が最優先**の設計思想と噛み合う。リールは中央・大きく・一目で判別（`CLAUDE.md` のゲームUI原則）
2. **AIっぽさを構造的に回避できる**。AI画像の違和感の主因は「ディテールが過剰にリアルなのに構造の一貫性がない」こと。色数と線を絞れば、そもそもその破綻が起きない
3. 現行のスマホゲームと**被らない**

---

## 2. 絵づくりの5原則

| # | 原則 | 具体 |
|---|---|---|
| 1 | **線は太く、断定的に** | 輪郭は均一な太線。かすれ・ぼかし禁止。※実機でも線を太くする（印刷の色ズレを隠せる）のが定石 |
| 2 | **色数を絞る** | 1枚あたり**6色以内**＋黒。中間色を作らない |
| 3 | **ベタ塗り主体** | グラデーションは使うなら**3段階まで**の段階的トーン。連続グラデ（エアブラシ）は禁止 |
| 4 | **光源は1つ** | 上前方から。ハイライトは必ずその向きに揃える。「あちこちが光る」のがAI臭の元 |
| 5 | **情報量にメリハリ** | 見せ場（図柄・ロゴ）に密度を集中。背景は面で整理。**全面に均等な描き込みをしない** |

---

## 3. 配色

黒地に蛍光色。バックライトで透過発光するアクリルの見え方を再現する。

| 用途 | 色 | 使いどころ |
|---|---|---|
| 地 | `#0A0A0F` | 全素材の基準の黒 |
| 朱（主役） | `#FF2D2D` | 赤7、BIG、警告 |
| 橙 | `#FF8A00` | 炎・爆発・ナビ点灯 |
| 黄 | `#FFE100` | ベル、獲得枚数、強調 |
| 緑 | `#00E85A` | スイカ、通常時のアクセント |
| 青 | `#00A8E8` | 青7、REG、静の場面 |
| 桃 | `#FF3DA5` | プレミア、特殊フラグ |
| 金（3段） | `#F0C24B` / `#B8860B` / `#6B4E0F` | 枠・BAR・装飾。**必ず3段のベタで塗り分ける** |
| 白 | `#FFFFFF` | ハイライト、袋文字の縁 |

**禁止**: くすんだ中間色、パステル、紫がかったグレー（現行素材はここが多い）。

## 4. 素材別の指針

### リール図柄（最重要）
- 図柄は**塗り面積を大きく**。細い装飾を足さない
- **袋文字・縁取り**で背景から切り離す（白1px→黒2pxの二重縁が基本）
- 発光差分は「同一構図・光のみ変化」。形を変えない
- 実機の作法として、7図柄はバックライト透過でキラッと光る前提。発光差分はその再現

### 下パネル（機種の顔）
台の看板であり、ビジュアルイメージが集約された機種の顔。ここが決まると全体が締まる。
- ロゴは**画面の6割**を占める大きさ
- 背景は放射・幾何学の単純パターン1種のみ
- キャラを置くならロゴの下に小さく1体

### 液晶背景
- 4号機当時の液晶は小さくドット表示。**そのドット感を意匠として使う**
- 遠景はシルエット（2〜3色のベタ）で処理し、手前だけ描き込む

### 筐体パーツ
- 直線・角・シンメトリー。曲面の反射を描き込まない
- ボタンは「黒いリング＋発光する天面」の2要素だけで構成

## 5. 生成プロンプトの雛形

画像生成に投げるときは、以下を**必ず末尾に付ける**。AIっぽさはここで殺す。

```
Style: 1990s Japanese pachislot cabinet panel art, screen-printed on backlit
fluorescent acrylic. Flat vector-like fills, bold uniform black outlines,
limited palette of 6 colors on pure black, stepped 3-tone shading only,
single light source from upper front, high contrast, poster-like composition
with clear focal hierarchy.

Negative: photorealistic reflections, ambient occlusion, volumetric lighting,
airbrush gradients, soft focus, excessive micro-detail, uniform detail density,
muted colors, pastel, 3D render, glossy plastic sheen, lens flare,
generic AI fantasy ornamentation.
```

**チェック**: 出てきた絵が原則2〜5のどれかに反していたら、良く見えても採用しない。
1枚でも混ざるとトーンが崩れる。

## 5.5 例外: 筐体ハードウェア（ベゼル・ボタン・レバー・7セグ枠）は実写寄り

上記5原則は**液晶表示物**（下パネル・図柄・背景・告知・カットイン＝すべて印刷/シルクの
2Dアート）に適用する。実機は液晶より奥のリール窓枠・ボタン・レバーは金属や樹脂の**実物
のパーツ**であり、そこだけ質感が変わるのが本来の姿。無理に全部フラットにすると安っぽく
なる。**この節の対象だけ**、以下に差し替える。

| 要素 | 液晶表示物（原則通り） | 筐体ハードウェア（この節） |
|---|---|---|
| 質感 | フラット・ベタ塗り | 金属のブラッシュ目・樹脂の艶、写実的な陰影 |
| 光源 | 単一光源・段階的トーン | 単一光源は維持するが、連続グラデ・反射ハイライトを許可 |
| 輪郭 | 太い均一な黒縁 | 輪郭線は使わない（実物に縁取り線は無い） |
| 配色 | 9色パレット厳守 | パレットは基調として維持しつつ、金属色（グレー・黒鉄）を追加可 |

- 完全なフォトリアルではなく、**「今すぐ触れそうな質感」**が目標。プラスチックの安っぽい
  テカリ・金属の鏡面反射のしすぎは禁止（AIっぽさの再発）
- 光源は1つに固定（原則4は維持）。あちこち反射させない
- 数字や文字（BAR・CREDIT等）は実機同様、樹脂に印字された書体にする。手描き感を出さない

## 6. 現行素材との差分

`assets/_source/` の7枚は「ネオン雨の裏路地＋和風マスコット」で、この路線とは合わない。
差し替えの優先順位は下記。**上から1枚ずつ**、スタイルガイドに沿っているか確認しながら進める。

| 順 | 素材 | 理由 |
|---|---|---|
| 1 | 下パネル（ロゴ） | 機種の顔。ここが基準になる |
| 2 | リール図柄16枚 | 常時見えている。視認性に直結 |
| 3 | 筐体パーツ | 枠・ボタン・レバー |
| 4 | 液晶背景8枚 | 面積は大きいが、上3つが決まってから |
| 5 | 告知・カットイン | 最後 |

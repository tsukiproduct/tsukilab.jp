# 月詠リリックモーション：演出研究メモ

参考資料を見て抽出した原則と、月詠として実装する方法。JIZURA のコード、画像、テンプレートは使用しない。

## 参考から得た原則

- [JIZURA](https://github.com/852wa/JIZURA) はレイアウト・動き・装飾・つなぎ・仕上げを別々の部品として組み合わせ、拍にカットを合わせる。月詠は曲の構造と歌詞の意味を一緒に演出へ渡し、ユーザーが各行の判断を上書きできる設計にする。
- [TextAlive](https://junkato.jp/publications/chi2015-kato-textalive.pdf) は音声との同期、タイムライン編集、プログラムで増やせる動きを組み合わせる。月詠でも自動の結果を開始点とし、歌詞と時刻を編集可能に保つ。
- [Green Day「Troubled Times」制作記録](https://manuviqueira.com/videos/music-videos-sports/)では、文字だけでなく歌の主題に合わせた画像・編集・タイポグラフィーの連携が作品になっている。月詠は曲全体の場面構成や絵作りを今後さらに強化する。
- [ボカロMVの文字演出に関する制作記事](https://videosalon.jp/premium/vsw307_t2/)は、世界観と文字デザインを両立させることを扱う。既存作品の再現ボタンは設けず、紙、墨、光、格子など独自の視覚語彙で構成する。

## 今回入れたもの

| 構成要素 | 実装 |
| --- | --- |
| 音の時間軸 | 音声の立ち上がり候補・推定BPM・8秒区間の相対的な強弱を抽出する |
| 演出判断 | 歌詞・時刻・近傍の拍と区間強度を Jev に送る。音声そのものは Jev に送らない |
| 文字 | スラム、ワイプ、パルス、残像、交互の跳ねを追加。特に強い動きは文字を一行として読める状態に収束させる |
| 背景 | パンクジン、ネオンクラブ、墨と余白、サンライズを含む10種類のテンプレート |
| 手直し | 行を選び、動き・配置・大きさを上書き。曲の再生時刻は歌詞の開始位置を保つ |

## 次の研究・実装候補

1. ボーカルを別トラックで解析し、単語またはモーラ単位の発声時刻を推定する。今の拍候補はキックやスネアを含む楽曲の瞬間で、歌の各音節とは一致しない。
2. Aメロ、サビ、落ちサビを反復と音色の変化から推定し、背景・色・カメラの切替をセクション単位で構成する。現在の8秒区間は相対的な強弱のみ。
3. 文字をマスク・縁取り・紙片・影・透過素材などの独立したレイヤーにし、同じテンプレート内でも場面ごとに変化させる。
4. ビートの正拍・裏拍を人が編集できるタイムラインを設け、テンポ推定の半拍・倍拍や不規則な曲を補正する。

推定のBPMと拍は確定値ではない。サンプル曲で視覚確認し、誤判定を手直しできる設計を優先する。
